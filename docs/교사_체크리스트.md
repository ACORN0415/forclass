# 교사 체크리스트 — GPU 아레나 특강 (7교시)

## 수업 1주 전 — 교실 네트워크 점검 (가장 중요)

학교 PC 1대로 아래를 **실제 교실에서** 확인한다. 여기서 막히면 수업 당일 손쓸 수 없다.

- [ ] 선생님 노트북에서 `python arena_server.py` 실행 → 출력된 주소(`http://192.168.x.x:8000/`)를 학생 PC 브라우저에 입력해 접속되는가
- [ ] 접속 안 되면 순서대로:
  1. 노트북 방화벽에서 Python 인바운드 허용 (Windows: 처음 실행 시 뜨는 "액세스 허용" 창에서 **개인·공용 둘 다** 체크)
  2. 학생 PC와 노트북이 **같은 네트워크**인가 (학교 Wi-Fi는 AP 격리로 PC끼리 통신을 막는 경우가 많다 → 유선 랜 또는 아래 플랜 B)
  3. 포트 바꿔 보기: `python arena_server.py 8080`
- [ ] 학생 PC 브라우저가 Chrome/Edge인가 (IE·구버전은 WebSocket 불안정)
- [ ] 학생 PC에서 WASD·마우스 입력이 되는가 (한글 입력 상태에서도 동작하도록 만들어져 있음)

### 플랜 B (교실 네트워크가 막혔을 때)

| 상황 | 대응 |
|---|---|
| Wi-Fi AP 격리로 PC끼리 통신 불가 | 선생님 휴대폰 **핫스팟**을 켜고 노트북 + 학생 PC(무선 가능한 것만)를 거기 연결. 유선 PC는 솔로 모드 |
| 아예 서버 접속이 안 됨 | `GPU아레나.html` 파일을 USB/공유폴더로 배포 → 각자 **혼자 연습**(봇전)으로 5교시 진행. 통계·캐릭터·맵 모두 동작함. 6교시 전략 봇은 "규칙 직접 만들기"로, 제출은 종이/구글폼으로 받아 선생님이 `submissions/`에 저장 |
| 서버는 되는데 느림 | `node host.js --bots` 로 경기 계산을 노트북 터미널에 맡기고 선생님은 브라우저로 [관전] |
| Claude Code가 안 됨 | 6교시: "규칙 직접 만들기" 드롭다운으로 봇 제작 → 선생님이 `bots/`에 JSON 저장 → `node league.js`. 7교시 해킹전은 `--audit` 탐지와 CLAUDE.md 읽기 토론 중심으로 |

## 당일 교실에서

- [ ] 서버 켜고 주소 칠판에 크게 (한 줄: `http://192.168.x.x:8000`)
- [ ] 선생님은 방을 만든 뒤 [참가 | 관전] 에서 **관전** 선택 → 학생 10명이 모두 자리에 앉고, 선생님 화면은 전체 시야라 그대로 프로젝터에 띄우면 됨
- [ ] 경기를 일찍 끝낼 땐 오른쪽 [경기 그만두기] 를 두 번 → 그때 점수로 결과 화면
- [ ] 학생 닉네임 규칙 공지: **반-번호-이름** (예: `3-12김철수`) — 재접속·봇 파일명이 이 이름을 따라감
- [ ] 소리는 끄게 (HUD의 🔊 버튼) — 30대가 동시에 나면 시끄러움
- [ ] 브라우저로 방장을 할 때는 **방장 탭을 다른 탭 뒤로 숨기지 말 것** (크롬이 뒤쪽 탭을 멈춰서 모두의 경기가 멈춤). PPT를 같이 띄우려면 창을 따로 열거나 `node host.js` 사용
- [ ] 한 방 정원은 학생 10명(host.js 사용 시) / 선생님 포함 10명(브라우저 방장 시). 반 인원이 많으면 방을 여러 개

## 용어 통일 (PPT ↔ 게임)

| PPT | 게임 화면 | 수업 중 말할 때 |
|---|---|---|
| CPU 진영 / GPU 진영 | 캐릭터의 CPU형 / GPU형 (팀은 A·B로 따로) | 결과표의 CPU형·GPU형 열이 하드웨어 비교, 팀 승패는 조합의 결과 |
| SM · Warp · 쓰레드 | 코어 폭(동시 발사) · warp 효율 | 16발 = warp 32쓰레드의 축소판이라고 한 번 짚기 |
| 메모리 벽 / HBM | 탄약·메모리 슬라이더 | "메모리가 작으면 탄약이 금방 떨어진다 = 메모리 벽" |
| 커널 런치 지연 | 던지기 준비시간(windup) | 결과표 '지연(latency)' 행 |
| 처리량(throughput) | 초당 눈덩이 | 결과표 그대로 |
| warp divergence | warp 효율 · 재장전 길어짐 | 결과표 그대로 |
| 정밀도(FP16/FP8) | 해상도 % | "해상도 낮추기 = 정밀도 낮추기" 비유 |
