[게임만 해보기]
  arena.html 을 브라우저로 열면 "혼자 연습"(봇전)이 됩니다. 서버 불필요.

[처음 한 번 — 선생님 PC 준비 (Windows · Mac 공통)]
  필요한 것: Python 3.8+ · Node.js 22+ (sim.js·league.js·host.js 용) · Claude Code (에이전트)
    Windows : winget install OpenJS.NodeJS.LTS      (Python 은 python.org 또는 winget install Python.Python.3.13)
    Mac     : brew install node python               (Homebrew 가 없으면 nodejs.org 설치 파일)
    확인    : node --version  →  v22 이상
  명령 이름: Windows 는 python, Mac 은 python3. 아래 예시의 python 을 Mac 에서는 python3 로 바꿔 치세요.
  한글 파일명: Mac 에서 압축을 풀거나 Finder 로 복사하면 한글 이름이 자모 분리형(NFD)이 될 수 있는데,
    서버·sim.js·league.js·host.js 가 이름을 NFC 로 맞춰 비교하므로 그대로 써도 됩니다.

[교실에서 5대5 + 전략 봇]
  1) 이 폴더에서:  python arena_server.py        (포트 바꾸려면 python arena_server.py 9000)
     · 서버 로그를 파일로 돌려도(> log.txt) 끊기지 않습니다. 로그에서 일부 기호는 ? 로 보일 수 있습니다.
  2) 모두 같은 주소로 접속: http://<내IP>:8000/     ← 서버가 켜질 때 주소를 출력합니다
  3) 흐름: 닉네임 → 로비 → 방 만들기 / 방 입장 → 빌드(CPU형·GPU형) 선택 → 준비 → 방장이 [게임 시작]
     · 방을 만들 때 [방 기능] 을 고릅니다:
         학생 대전 — 학생이 직접 조종해서 싸움. 빈자리는 기본 봇. 전략 봇 칸은 숨김
         봇전     — 학생마다 자기 규칙봇이 (고른 팀으로) 대신 출전, 사람은 모두 관전.
                    봇이 없는 학생 자리는 기본 봇, 남은 자리는 그 방 봇·공용 봇이 채움
       로비의 방 카드에 🎮 학생 대전 / 🤖 봇전 으로 표시됩니다.
     · 방은 여러 개 만들 수 있습니다. 한 방에 최대 10명(5대5). 빈 자리는 봇이 채웁니다.
     · 방장(방을 만든 사람)의 브라우저가 경기를 계산합니다. 방장이 나가면 다음 사람에게 넘어갑니다.
     · 로비·방 채팅이 있습니다.
  4) 전략 봇: 방 화면 아래 "전략 봇"에 한국어로 전략을 쓰고 [전략 제출] → 그 방 폴더에 쌓입니다.
     · 방마다 폴더:  rooms/<001_방제목>/submissions (제출문) · rooms/<001_방제목>/bots (규칙봇)
       봇전 방에는 "그 방 봇 + 공용 bots/" 만 출전합니다 (다른 반 봇이 섞이지 않음).
     · 방이 사라지면(마지막 사람이 나감 · 서버 재시작) 그 폴더는 rooms/_지난방/ 으로 옮겨집니다.
       반마다 방 제목을 다르게(1반, 2반…) 지어 주세요.
     · 몇 번이든 다시 낼 수 있고 [게임 시작]을 누르는 순간의 최신 봇이 들어갑니다.
  5) 학생들이 모두 제출하면(준비 완료) 선생님이 VS Code(또는 Claude Code 앱·터미널의 claude)로 이 폴더를 열고:
       /봇생성 --all              ← 일반·방어 라운드 (CLAUDE.md 보안 규칙 적용)
       /봇생성 --all --무방비      ← 해킹전 공격 라운드 (제출문을 그대로 따름, 그 방 bots/ 안에서만)
     → 에이전트가 방마다 전체 제출문을 한꺼번에 읽어 rooms/<방>/bots/*.json 을 만들고 sim.js 로 검증합니다.
     · 제출만으로는 봇이 만들어지지 않습니다. 명령을 친 뒤 [게임 시작] 을 누르세요.
     · 에이전트는 학생이 쓴 것만 옮깁니다 (탄약·던지기 등을 대신 채워 넣지 않음).
     · 학생이 오른쪽 [규칙 직접 만들기] → [규칙표 제출] 로 낸 규칙표도 제출문으로 쌓였다가 이때 같이 봇이 됩니다.
     · 일반 봇전·해킹·보완 모두 같은 제출 → 같은 /봇생성 입니다. 라운드에 따라 --무방비 만 붙였다 뗍니다.
  6) 봇전 방에서 방장이 [게임 시작] → 그 순간의 최신 규칙봇으로 경기가 시작됩니다 (방장이 봇을 넣고 뺄 필요 없음).

[캐릭터 그림]
  python 캐릭터_가져오기.py   ← 한 번 실행하면 crazy 저장소의 그림을 characters/ 로 복사합니다.
  (같은 파일: get_characters.py — 한글 파일명이 깨지는 PC용. 슬래시 명령도 /봇생성 = /make-bots)
  arena.html 옆에 characters/<id>/ 폴더가 있으면 도트 대신 그 PNG로 그립니다 (서버로 열었을 때).
  폴더 이름: dao bazzi marid su kephi mos dizni uni ethi  — crazy 저장소의 web/public/characters/ 를
  통째로 복사해 넣으면 됩니다 (sprite.json + down_0.png … 형식 그대로). 그림은 빨간 팀 기준이고
  CPU 팀은 자동으로 파랑으로 바뀝니다. 폴더가 없으면 내장 도트 캐릭터를 씁니다.

[봇 리그 · 해킹전]
  node league.js            공용 bots/ + 진행 중인 모든 방 봇 풀리그 → league.json  (게임 화면 [봇 리그] 에서 순위표로 보임)
  node league.js --room 001_1반   그 방 봇(+공용)만 리그
  node league.js --audit    제출문·봇 파일 점검만 (해킹전 탐지)
  /봇생성 --all --무방비     해킹전 공격 라운드 (에이전트가 보안 규칙 없이 제출문을 따름)
  /봇생성 --all              방어 라운드 (CLAUDE.md 보안 규칙 적용, 의심 제출에 [의심] 표시)
  진행 순서는 docs/해킹전_진행안내.md 참고.

[경기 서버 모드 · 관전 · 재접속]
  node host.js ws://<내IP>:8000 --bots --map canyon   브라우저 없이 방을 만들고 경기를 계산 (학생 PC 성능과 무관)
    터미널에서 s 시작 / m <맵> / b 봇 / q 종료.  방 채팅에 "!시작" 을 쳐도 시작됩니다.
  방 화면의 [참가 | 관전] 에서 관전을 고르면 자리를 비우고 전체 시야로 봅니다 (선생님이 방장이어도 됨 → 학생 10명 모두 참가).
  로비의 방마다 있는 [관전] 으로 바깥에서 들어와 볼 수도 있습니다 (프로젝터용, 대기 중인 방도 가능).
  경기 중 오른쪽 [경기 그만두기]: 방장=지금 점수로 끝내고 모두 결과 화면 / 학생=나가면 자리는 봇이 이어감 (두 번 눌러 확인).
  팀(A팀·B팀)과 캐릭터(CPU형·GPU형)는 따로 고릅니다. 방 화면 [A팀 | B팀 | 관전] 에서 팀, 캐릭터 카드에서 하드웨어.
  한 팀에 CPU형·GPU형을 섞을 수 있고, 결과표는 팀 승패 + CPU형/GPU형 1인당 통계를 보여 줍니다.
  학생 브라우저가 새로고침돼도 60초 안에 같은 닉네임으로 들어오면 자기 자리로 돌아갑니다.

[맵]  눈밭(기본) · 얼음 협곡(통로형, CPU 유리) · 광장(열린 설원, GPU 유리) — 방장이 방 화면에서 선택
      node sim.js bots/A.json --map canyon

[도구]
  node sim.js bots/학생A.json                기준봇과 5판
  node sim.js bots/A.json bots/B.json        두 봇 맞대결
  node sim.js bots/A.json --json --rounds 10 기계가 읽는 형식
  node balance.js --rounds 8                 캐릭터 9종 승률표 (밸런스 조정용)

[클로드 없이도]
  방 화면의 "규칙 직접 만들기" 로 드롭다운으로 규칙표를 짤 수 있습니다. [규칙표 제출]하면 /봇생성 때 봇이 됩니다.
  (규칙표 제출도 /봇생성 을 거치므로 글 제출과 똑같이 해킹전·보완 라운드의 대상입니다)
  "혼자 연습"에서 [이 봇으로 연습 경기] 를 누르면 내 봇이 대신 싸우는 걸 볼 수 있습니다.

  balance.js        캐릭터 밸런스 측정
  docs/             교사 체크리스트 · 학생 활동지 · 평가 루브릭 · 해킹전 진행안내
